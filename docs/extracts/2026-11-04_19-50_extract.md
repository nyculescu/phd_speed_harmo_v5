## Names

- **r1m3:** 1 ramp lane, 3 main lanes. Code and old records call it `m32`. **r2m3:** a second ramp and acceleration lane 4a. **r1m2:** 2 main lanes, a transfer check.
- **P0:** r1m3 with `lcAssertive` 1.4 and the smooth no-undertaking rule. **P0c:** P0 with the rule's cap eased every 0.1 s (`docs/research/p0c/plant_p0c.json`).
- **Per-CAV:** one shared policy deciding for each ALKS. Never call it C. Older files say C, F, G, H, C0-C2.
- **ALKS:** the automated vehicles the controllers act on, 50 % of the fleet; human cars 42.5 %, trucks 7.5 %.
- **d0-d6:** the trained DRL policies, one per learner.
- **p333, a333:** digits are headway levels up, merge, down: 0 = 1.6, 1 = 1.2, 2 = 1.0, 3 = 0.8 s. **r4a1:** 1.2 s on 4a, 0.8 s elsewhere. **lr1000_10:** 0.8 s, or 1.2 s if mean speed in the next 1,000 m is below 10 m/s.
- **X1:** tapered slowdown on edge 4. **X2:** on edge 3. **H1:** slow truck. **H2:** ramp bursts. **S:** steady.
- **Levels:** total demand in veh/h: 4,090, 4,600, 5,300, 6,000.
