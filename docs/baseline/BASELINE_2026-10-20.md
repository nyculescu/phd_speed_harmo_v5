## 6. Operating rules in force

- **Protocol before data.** Every author decision gets a V entry, committed the same turn.
- **Run once, with sentinels.** A bug found after results means: fix, re-run with the same seeds, report both outcomes.
- **Decisive runs** start from a detached frozen worktree at the run commit, as `systemd-run --user` units: 32 workers, CPU guard 0.90 (V93). The pad and fans are controlled by the author.
- **Background work runs outside VS Code** (V110/V111): helper agents run as headless jobs via `tools/claude-job` (outputs in `v5b1_runs/jobs/`); small tasks are done in the session.
- **Lean mode** (V107): one reviewer, one builder, one code reviewer and one verifier per study.
- **Honesty:** pre-registered vs descriptive labels; no novelty claims; [VERIFY] on anything unread; full operating maps.
