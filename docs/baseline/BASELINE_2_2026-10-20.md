## 4. Rules for the paper (in force)

- **Every number in the paper** comes from a committed result note or JSON listed in BL-1. Figures are generated by scripts that read only those files.
- **Fixed terminology:** L0 (always-on: N, FX, FB, PI, AD), ID (presence), IP (type), L2 (hindsight; OR_in upper bound, ORX lower bound). This is **mainline** metering, never "ramp metering".
- **No novelty words.** Pre-registered (P) and descriptive (D) numbers are not mixed. The C1 claim is always given with its CI [7.3, 23.7] and its scope (one cell).
